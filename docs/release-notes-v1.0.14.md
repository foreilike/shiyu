## 拾语 v1.0.14 —— 首个开源版本

面向中文母语者的日语 / 英语口语陪练 Android 应用。

---

### 📦 关于附件的 APK（请先读这一段）

附件 `Shiyu-v1.0.14-demo-nokeys.apk` 是**演示版**，可以安装、浏览全部界面。

> **⚠️ 该 APK 不含任何 API Key，因此「实时语音对话」「场景对话」「单词朗读」等需要模型的功能不会真正跑通。**

**完整功能请填自己的 Key**，两种方式任选：

1. **改配置文件**（适合自行编译）：把 `app/src/main/assets/preset_config.example.json`
   复制为同目录下的 `preset_config.json`，填入自己的 Key 后重新构建；
2. **在 App 里直接填**（免编译）：安装后进「我的 → API 设置」，
   按组（对话 / 语音识别 / 语音合成 / 实时语音）分别填写接口地址、Key、模型名，
   保存后立即生效。

需要的服务与模型见下文「Step 模型使用情况」。

### 本版亮点

**🎙️ 实时语音「自动跟随语种」**
取消「练日语 / 练英语」分入口。模型按用户这句话的**实际发音**判断该用什么语言回，
同一场对话里中 → 英 → 日切换都能跟上。

关键实测发现：模型判语种**只看音频、与转写文本无关** ——
实测有两句话的实时转写分别成了阿拉伯文乱码和**空字符串**，模型照样用正确的语言作答。
这个结论直接否掉了「先在客户端判语种再告诉模型」的方案。

**🗣️ 实时语音改为「自由聊天」**
修掉了「每次都问名字」的死板问题。根因是两处叠加：实时语音入口写死取第一个场景
（= 自我介绍），而提示词又要求「引导学习者说出目标表达」，其第一条正是 `My name is ...`。
修法不只是"写得更自然"，而是**把具体的坏行为点名禁止**。

**🔊 语音识别按语言分流**
带中文口音的日语会被某家 ASR 判成中文并输出谐音（`おはようございます` → `哦，还有，给我唱野马写`）。
实测其 `language` / `prompt` / `hotwords` 三个参数**都改不动输出文字体系**（6 种组合），
最终按语言切到另一条通路，并把新通路的延迟从 **137 秒压到 1~2 秒**（关闭深度思考模式）。

### 功能一览

- 实时语音对话（自动跟随语种 · 字幕 + 中文翻译 · 打字兜底 · 提示话题）
- 场景对话练习（5 场景 × 2 语言，AI 扮演角色）
- 单词 SRS 复习（SM-2 算法，12 本词书 / 题库全部离线内置）
- 朗读（云端 TTS + 磁盘缓存 + 预取）
- 学习统计、成就体系、历史会话回看

界面截图见 [README](https://github.com/foreilike/shiyu#界面预览)。

### Step 模型使用情况

| 环节 | 模型 | 接入方式 |
|---|---|---|
| 文字对话 | `step-5-preview` | `POST /chat/completions` |
| 实时语音 | `stepaudio-3-realtime-preview` | `WSS /v1/realtime` 双向流式 |
| 语音合成 | `stepaudio-2.5-tts` | `POST /audio/speech` |
| 语音识别 | `stepaudio-2.5-asr` | `POST /audio/asr/sse` |

> 注：**语音识别环节，日语已按语言分流到火山方舟**（原因见上文「语音识别按语言分流」），中英仍走 `stepaudio-2.5-asr`。

### 🔒 密钥安全说明

**本仓库、以及本页附件，均不含任何 API Key。**

`app/src/main/assets/preset_config.json` 已被 `.gitignore` 排除；
历史上出现过的密钥也用 `git filter-repo` 从全部提交中清除（已逐 blob 扫描确认残留为 0）。
仓库里只有不含密钥的 `preset_config.example.json`。
